Reports npm, pnpm, yarn or bun in commands or prose ("we use yarn") when the packageManager field or the lockfile says another one.

Example: Install with pnpm install (the repo has package-lock.json)

Quick fix: Replace `pnpm` with `npm`. Every finding also offers "Disable CD003 for this line" (an HTML comment, or a YAML comment in frontmatter) and "Ignore CD003 in this project".

Context Drift runs locally, with no network and no account.
