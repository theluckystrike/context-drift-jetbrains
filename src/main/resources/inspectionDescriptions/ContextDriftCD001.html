Reports a documented command that the repo does not define: npm run X, pnpm X, yarn X, bun run X, make X, just X, task X, cargo -p/--bin, and uv run X / poetry run X.

Example: Run: npm run buidl (package.json defines build)

Quick fix: Replace with "build". Every finding also offers "Disable CD001 for this line" (an HTML comment, or a YAML comment in frontmatter) and "Ignore CD001 in this project".

Context Drift runs locally, with no network and no account.
