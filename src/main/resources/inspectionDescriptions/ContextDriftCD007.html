Reports an instruction line (5 or more words) that repeats an earlier line of the same file, and, as a weak warning, a line that is also in a file the same agent loads at the same time (a root and a nested CLAUDE.md, CLAUDE.md and CLAUDE.local.md, a root and a nested AGENTS.md). List markers, case, spaces and end punctuation are ignored.

Example: - Run the tests before you commit.
...
- run the tests before you commit

Quick fix: Remove this duplicate line. Every finding also offers "Disable CD007 for this line" (an HTML comment, or a YAML comment in frontmatter) and "Ignore CD007 in this project".

Context Drift runs locally, with no network and no account.
