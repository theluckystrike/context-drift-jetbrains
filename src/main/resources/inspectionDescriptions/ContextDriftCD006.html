Off by default. Turn on "Check staleness with git" in Settings | Tools | Context Drift. Reports a file whose last commit is older than 180 days when the repo has 50 or more commits since (read-only git log, 3 s timeout).

Example: Last changed 412 days ago; the repo has 380 commits since.

Every finding offers "Disable CD006 for this line" and "Ignore CD006 in this project".

Context Drift runs locally, with no network and no account.
