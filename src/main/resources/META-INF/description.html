Context Drift finds the commands, paths and versions in your AGENTS.md, CLAUDE.md, Cursor, Copilot and Windsurf rules that no longer match your repo.

Coding agents read these files and trust them. When code moves on and the file stays the same, the agent runs a script that was renamed, opens a file that moved, or installs with the wrong package manager. Context Drift compares what the file says with what is in the repo and marks each mismatch in the editor.

  • Commands that the repo does not define, such as npm run X, pnpm X, make X, just X, task X, cargo -p and uv run X (CD001).
  • Backticked paths, links and cd targets that do not exist, and Cursor or Copilot globs that match no file (CD002).
  • A package manager that the lockfile contradicts, for example pnpm in the file and package-lock.json in the repo (CD003).
  • Node, Python and Go versions that .nvmrc, engines, requires-python or go.mod contradict (CD004).
  • Two files that give different commands for the same job, like make test in AGENTS.md and npm test in CLAUDE.md (CD005).
  • Files that have not changed while the repo kept moving, read-only git, off by default (CD006).
  • The same instruction twice in one file, or in two files that the same agent loads (CD007).
  • Files over the size an agent reads: 32 KiB of AGENTS.md for Codex, 40,000 characters of CLAUDE.md for Claude Code, 4,000 characters for Copilot code review, 6,000 for .windsurfrules (CD008).

Quick fixes replace a wrong script, path, package manager or version in one click, and "Fix all" cleans the whole file. Each rule is a normal inspection, so you can turn it off or change its level under Editor | Inspections | Context Drift. The Context Drift tool window lists every finding in the project.

It runs locally, with no network and no account. It skips text that reads as negated, historical or an example, so it reports fewer things and most of what it reports is real.
